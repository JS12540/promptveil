# Codex Challenge submission checklist

## Release and demo

- [ ] Public source, meaningful commit history, contributor instructions, notices, and license.
- [ ] Clean installs on documented platforms, versioned assets, and checksums.
- [ ] Extension ZIP, CLI tarball, PWA and site links, and clear usage instructions.
- [ ] Synthetic demo covers ₹25,000 allowed, customer ID masked, fake credential blocked, mobile offline scan, CLI, and verified Codex path.
- [ ] If aggregate analytics ships, demonstrate local aggregate-only storage.
- [ ] Actual evaluation metrics, latency and installed/download size, versions, and limitations.
- [ ] All eight rubric stages indexed with actual Codex settings, reviewed diffs, commit references, and CI runs.

## Form fields

| Field | Link to submit |
| --- | --- |
| GitHub Repository Link | Public repository root with README and docs |
| Codex Evidence Pack Link | Tagged evidence index, or alternate format required by organizer |
| Live Project URL / Runnable Release Link | Tagged runnable release with PWA and demo links in its notes |

- [ ] Confirm organizer deadline, time zone, and accepted formats.
- [ ] Open each exact submission link signed out. Verify the PWA and install links.
- [ ] Submit and record confirmation and UTC time.
