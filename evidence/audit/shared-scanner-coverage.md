# Shared scanner and coding-agent coverage

G6 uses the same local scanner in the browser, CLI, native prompt adapters, and Codex relay. The customer label rule generalizes to a single insertion, deletion, substitution, or adjacent swap in an explicit customer ID label. A generated regression exercises every single-edit variant over the Latin alphabet. New fixtures cover labeled names, street addresses, birth dates, US SSNs, vendor-prefixed credential assignments, and authorization headers.

Gemini CLI uses its documented `BeforeAgent` denial response. The installer and hook command passed with isolated settings. The packaged hook also returned a denial with a value-free reason. Adapter fixtures exercised Claude Code, Codex, Cursor, and Gemini. Live Gemini CLI and Chrome runs remain pending. [Gemini CLI hook contract](https://geminicli.com/docs/hooks/reference/#beforeagent)

The 650-prompt synthetic evaluation measured scanner p95 at 0.020 ms on macOS with Node v26.0.0. It reported zero marker leaks and zero benign changes. Typecheck, 38 passing tests, build, and release checks completed locally. One loopback test was skipped by the local environment. The results establish coverage for the test suite.
